# 📚 Читательский дневник — Telegram-бот

Бот для отслеживания прочитанных книг с поддержкой:
- Добавления книг по автору, названию и оценке
- Просмотра списка по годам и месяцам
- Удаления книг с подтверждением
- Персональной статистики

## 🛠 Технологии
- Python 3.11+
- `python-telegram-bot`
- SQLite (локальное хранилище)
- Railway.app (хостинг)
